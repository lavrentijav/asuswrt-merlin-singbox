# sbmerlin — sing-box для ASUSWRT-Merlin

Аддон, который поднимает на роутере ASUS прокси-ядро [sing-box](https://sing-box.sagernet.org)
и маршрутизирует трафик LAN по правилам: часть сайтов напрямую, часть — через Германию,
часть — через Финляндию. Настраивается из веб-интерфейса роутера, следит за живостью
узлов и сам обновляет geo-списки (РКН/антифильтр, российские сайты, сервисы, закрывшиеся от РФ).

Проверено на **RT-AC86U, Merlin 386.14_2, aarch64, sing-box 1.14.0**.

## Возможности

- **Маршрутизация по доменам, спискам, IP и портам** — правила применяются сверху вниз.
- **Группы узлов по странам** (DE, FI, NL…) с автовыбором самого быстрого живого узла
  (`urltest` внутри ядра). Если падает узел — трафик переезжает сам.
- **Поведение при полном отказе группы** настраивается на каждое правило:
  «блокировать» (kill switch, по умолчанию) или «пустить напрямую» — переключением
  занимается watchdog через clash-API, без перезапуска ядра.
- **Профили устройств**: MAC/IP → мимо прокси, общие правила, или весь трафик в конкретную страну.
- **Geo-списки с автообновлением**: домены компилируются в компактные `.srs`, а большие
  списки IP уходят в **ipset ядра Linux** — 8600 российских подсетей занимают 59 КБ и
  отсекают трафик до того, как он вообще дойдёт до sing-box.
- **Источники узлов**: ссылки `vless:// vmess:// ss:// trojan://`, подписки с автообновлением,
  сырой JSON outbound.
- **Экономия ОЗУ**: без TUN, без FakeIP, без `geoip.db`/`geosite.db`; `GOMEMLIMIT` настраивается
  из UI; загружаются только те rule-set, на которые ссылаются включённые правила.

## Установка

Нужен роутер на прошивке Merlin 384+ с USB-накопителем и установленным Entware (ставится из amtm).

```bash
mkdir -p /jffs/addons/sbmerlin && cd /jffs/addons/sbmerlin
curl -fsSL https://raw.githubusercontent.com/lavrentijav/asuswrt-merlin-singbox/main/install.sh | sh
```

Либо вручную: скопировать каталог `sbmerlin/` в `/jffs/addons/sbmerlin/` и выполнить

```bash
sh /jffs/addons/sbmerlin/sbmerlin.sh install
```

Установщик поставит `jq`/`curl` из Entware, скачает ядро sing-box под архитектуру роутера
(с проверкой sha256 из GitHub API), пропишет хуки в `/jffs/scripts/*`, задания cron
и смонтирует страницу в веб-интерфейс: **Tools → sing-box**.

## Как пользоваться

1. Вкладка **Серверы** — вставьте ссылки на узлы или адрес подписки. Страна определяется
   по названию узла (`🇩🇪 Германия Франкфурт`, `nfc_fi2`), группы создаются автоматически.
2. Вкладка **Правила** — «что совпадает» задаётся свободным текстом в синтаксисе,
   знакомом по Xray:

   | Запись | Что значит |
   |---|---|
   | `geosite:youtube` | готовый набор доменов из каталога sing-geosite (скачается сам) |
   | `geoip:ru` | набор IP-адресов страны из sing-geoip |
   | `rkn-domains` | свой список из вкладки Geo |
   | `example.com`, `*.example.com` | домен и его поддомены |
   | `*keyword*` | вхождение подстроки в домен |
   | `1.2.3.0/24`, `8.8.8.8` | IP-подсеть или адрес |
   | `protocol:bittorrent` | протокол, определённый по сигнатуре трафика |
   | `udp` / `tcp` | только этот транспорт |
   | `port:443`, `port:50000-65535` | порт или диапазон |

   Наборы `geosite:`/`geoip:` регистрируются и скачиваются автоматически при применении
   настроек — достаточно написать их в правиле.

   Готовый набор правил для России лежит в `sbmerlin/templates/rules-ru.json`
   (реклама в блок, торренты и РФ напрямую, дальше по категориям: видео, музыка,
   соцсети, AI, игры, IT, новости, инфраструктура).
   Первым правилом идёт **инфраструктура самого VPN-провайдера** (панель, подписка,
   адреса узлов) — она всегда направляется напрямую. Иначе туннель начинает зависеть
   от самого себя: когда узел падает, роутер уже не может достучаться до панели и
   обновить подписку, чтобы восстановиться. Список лежит в
   `sbmerlin/lists/provider-direct.lst` и обновляется по расписанию.
3. Вкладка **Geo-списки** — включите нужные (по умолчанию: домены РКН, сервисы против РФ,
   российские сайты и госсайты напрямую, российские IP в ipset).
4. Вкладка **Настройки** — включите sing-box и нажмите «Применить настройки».

### Проверка из консоли

```bash
/jffs/addons/sbmerlin/sbmerlin.sh status
```

Если в настройках задан отладочный порт, можно проверить, куда уходит конкретный домен:

```bash
curl -x http://127.0.0.1:7891 https://ipinfo.io/ip
```

## Как это устроено

```
LAN client ─► iptables mangle SBM_PRE ─TPROXY─► sing-box :7893 ─┬─► grp-FI (urltest: узлы FI)
     │            ├─ RETURN: приватные сети, роутер, ipset RU   ├─► grp-NL
     │            └─ TPROXY :7894 для устройств, привязанных к NL└─► direct / reject
     └─ DNS ─► dnsmasq ─► sing-box :7853 ─► dns-local (DNS провайдера) / dns-remote (DoH)
```

| Компонент | Файл | Назначение |
|---|---|---|
| Точка входа | `sbmerlin/sbmerlin.sh` | команды, хуки прошивки, события WebUI |
| Настройки | `lib/config.sh` | `settings.json`, импорт из WebUI, подписки |
| Генератор | `lib/generate.sh` + `templates/config.jq` | `settings.json` → `config.json` + `sing-box check` |
| Разбор ссылок | `lib/outbound.sh` | vless/vmess/ss/trojan, подписки, определение страны |
| Перехват | `lib/firewall.sh` | ipset + iptables (TPROXY, откат на REDIRECT) |
| Процесс | `lib/service.sh` | запуск с `GOMEMLIMIT`, clash-API, dnsmasq |
| Geo | `lib/geo.sh` | загрузка, компиляция `.srs`, ipset, атомарная замена |
| Failover | `lib/watchdog.sh` | живость, лимит RSS, переключение селекторов |
| WebUI | `lib/webui.sh`, `www/` | монтирование страницы, статус |

Конфигурация никогда не применяется вслепую: генератор прогоняет `sing-box check`,
и при ошибке ядро продолжает работать на прежнем конфиге, а текст ошибки уходит в лог.

## Потребление памяти

На RT-AC86U с 20 узлами, четырьмя rule-set и списком РКН (485 КБ `.srs`):

| Что | Сколько |
|---|---|
| RSS процесса sing-box | ~60 МБ (включая страницы 86-МБ бинарника) |
| ipset российских подсетей (8652 записи) | 59 КБ памяти ядра |
| Свободно на роутере после запуска | ~95 МБ из 426 МБ |

`GOMEMLIMIT` задаётся в UI («Лимит памяти ядра»), watchdog перезапускает ядро,
если RSS превышает заданный порог.

## Известные ограничения

- В режиме **REDIRECT** (если в ядре нет `xt_TPROXY`) проксируется только TCP; UDP и QUIC идут напрямую.
- Трафик самого роутера не перехватывается — это осознанное решение, чтобы не ломать
  обновления прошивки, VPN-клиенты и системные сервисы.
- Аппаратное NAT-ускорение не действует на проксируемый трафик; direct-трафик его не теряет
  благодаря отсечке через ipset.
- Порт DNS по умолчанию 7853: 5353 на прошивке занят `avahi-daemon`.

## Удаление

```bash
/jffs/addons/sbmerlin/sbmerlin.sh uninstall
```

Снимает хуки, cron, страницу WebUI, цепочки iptables и ipset; данные в `/opt/share/sbmerlin`
удаляются по запросу.
